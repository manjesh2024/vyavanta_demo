# VYAVANTA Brand Notes

**Brand:** VYAVANTA  
**Tagline:** Every Business. One Ecosystem.

## Identity

The selected direction is an orbit-like circular emblem in purple, violet, magenta/pink and orange gradients, paired with the original navy VYAVANTA wordmark and the exact tagline `EVERY BUSINESS. ONE ECOSYSTEM.`.

## Master-artwork rule

The clean supplied master artwork is the only authority for the production logo. Do not redraw, regenerate, approximate, recolour, restyle, simplify or reconstruct the emblem or wordmark. Background treatment may change only where an approved master variant supports it.

The source repository contains older Vyavsetu SVGs and its own asset README identifies them as approximations/traces. They may be retained as source-history assets, but they are not VYAVANTA logos and must not be presented as such.

A Library ZIP named `vyavanta_logo_assets.zip` was located. Its included README says the logo examples are raster crops from a brand-board image, not original editable/vector artwork. These crops are not production master assets.

## Theme direction

Intended palette direction: purple and violet; magenta/pink; orange and light orange; navy for text and dark surfaces; light lavender, soft pink, warm neutral and white surfaces.

No exact HEX values are authoritative in this file yet. Extract actual colors from the clean master artwork and document sampled HEX values, sampling method and semantic tokens once that file is available. HEX values printed on a visual reference board are provisional until validated against the master.

## Design-system requirements

- Shared light and dark themes with accessible contrast.
- Semantic tokens for primary, secondary, accent, surface, on-surface, border, success, warning and danger.
- Responsive desktop, laptop, store POS, tablet, Android and iPhone layouts.
- Readable typography, keyboard navigation and OS/browser zoom.
- Keep logo files immutable; theme variants must use approved original artwork.
- Document asset filename, source, background compatibility, minimum size and export format.

## Migration note

The copied prototype has not yet completed its visible logo/theme migration. Do not release or deploy the old source-brand UI under the VYAVANTA identity until approved master artwork is available and the brand-specific UI/documentation updates are validated.
