# VYAVANTA Brand Guidelines

**Brand:** VYAVANTA  
**Tagline:** EVERY BUSINESS. ONE ECOSYSTEM.

## Official logo assets

The light and dark horizontal logo variants and symbol-only icon in `assets/` use the VYAVANTA teal identity artwork supplied for this project.

- `assets/vyavanta-horizontal-light.webp` — full horizontal logo and tagline for light surfaces, web headers, POS, customer/merchant app bars, receipts and A4 print layouts.
- `assets/vyavanta-horizontal-dark.webp` — full horizontal logo and tagline for dark/navy/teal surfaces and dark application headers.
- `assets/vyavanta-mark-teal.webp` — symbol-only artwork for favicon and compact icon contexts.

Preserve the artwork and aspect ratio. Do not redraw, recreate, stretch, crop, recolour, retype or add effects. If an asset does not contrast with a surface, choose the correct supplied variant or adjust the surface rather than editing the logo.

Legacy `vyavsetu-*.svg` files remain only for migration traceability and must not be used as VYAVANTA branding.

## Palette from the supplied identity board

| Token | HEX | Usage |
|---|---|---|
| Primary teal | `#008B8A` | Brand primary, links and key indicators |
| Secondary teal | `#14B8A6` | Secondary actions and selected components |
| Aqua | `#22D4BF` | Focus ring, highlights and subtle interactions |
| Orange | `#FF8A3D` | Sparing accent, alert highlights and emphasis |
| Navy | `#0E2A5B` | Primary text, headings and dark surfaces |
| Silver | Logo's original neutral silver gradient | Neutral accents; keep the gradient in the logo untouched |

For interactive controls requiring white text, use a contrast-safe darker teal derived from the primary (such as `#006F70`) when necessary. That is a UI accessibility token, not a replacement logo color.

## Shared UI design system

- Light theme: white and pale neutral surfaces, navy text, teal CTA, aqua selection/focus, orange used sparingly.
- Dark theme: deep navy/teal surfaces, near-white text, brighter teal accents and visible borders.
- Use semantic tokens consistently across desktop, tablet, store POS, customer and driver experiences.
- Provide clear default, hover, active, disabled and keyboard-focus states on controls.
- Keep field labels, validation errors and placeholders readable; never rely on color alone for state.
- Validate contrast in light, dark, ocean, forest and high-contrast modes.
- Logo theme variant selection may change by surface; logo artwork itself must remain unaltered.
